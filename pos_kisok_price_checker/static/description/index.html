A faster price-checking experience for retail stores

Customers no longer need to ask staff for product prices. They scan the shelf QR code, point the camera at a product barcode, and receive the same price Odoo would apply for that store.

Public page per store

Each PoS store receives its own public URL, such as /price-check/store-a. The slug is generated automatically and can be edited.

Mobile barcode scan

Customers can scan using their phone camera. Manual barcode entry is also available for unsupported browsers or damaged barcodes.

Odoo price logic

Prices are calculated from the configured pricelist, store currency and tax display setting, including discount information.

Customer flow

Open the store QR page

Place the QR code on shelves, counters or store entrances.

Scan the product barcode

The mobile page uses the customer phone camera for lookup.

Show the exact price

Display product, price, tax mode and discount indicator instantly.

Included capabilities

EAN-13 / UPC-A cross lookup
Equivalent barcode formats resolve to the same product.
Product image and details
Customers can confirm they scanned the correct item.
Tax included or excluded display
Match the store's configured pricing display behavior.
Discount visibility
Show when pricelist rules reduce the displayed price.

Configuration inside PoS settings

  1. Open Point of Sale > Configuration.
  2. Select the PoS store.
  3. Open the Price Checker tab.
  4. Enable the checker and review the generated slug.
  5. Select tax display behavior and optional pricelist.
  6. Save and print the generated QR code.
Requirement: install the Python qrcode library: pip install qrcode.
