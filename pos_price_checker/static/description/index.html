POS Kisok Price Checker

Let customers scan and verify prices instantly

A public mobile page for each PoS store. Customers scan a product barcode and see the exact store price.

QR page per store Barcode scan Pricelist-aware

Built for real store-floor price checks

No kiosk hardware, no backend login and no website chrome. Just a focused, customer-facing price checker page that works from a phone camera.

URL

Public store URL

Each PoS store receives a dedicated public URL such as /price-check/store-a. The slug is generated automatically and remains editable.

BAR

Phone camera scanning

Uses the browser BarcodeDetector, plus manual barcode entry for unsupported devices.

AED

Accurate Odoo pricing

Computes the product price from the configured pricelist, store currency and tax display setting, including discount indication.

Mobile experience

Scan the barcode

Customers open the store QR page and point the camera at any product barcode.

View the exact price

The result page shows product details, price, tax handling and applicable discount.

Included capabilities

  • EAN-13 / UPC-A cross lookup for equivalent barcodes.
  • Product image and details for customer confirmation.
  • Tax included or excluded display based on configuration.
  • Discount visibility when pricelist rules reduce the price.
  • Standalone public page optimized for mobile use.
  • Printable QR code for shelves, counters or store entrances.

Configuration

  1. Go to Point of Sale > Configuration and open a PoS store.
  2. Open the Price Checker tab.
  3. Enable Price Checker. A public URL slug is generated automatically.
  4. Select whether prices are shown as tax-included or tax-excluded.
  5. Optionally configure a dedicated pricelist for the price checker.
  6. Save, copy the public URL or print the generated QR code.
Requirement: install the Python qrcode library to render QR codes: pip install qrcode.

Configure the public page, slug, pricing behavior and QR code directly from the PoS store form.
